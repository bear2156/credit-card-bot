# 🔐 نظام أتمتة إدخال بيانات البطاقات الائتمانية

## 📝 الوصف

تطبيق بسيط وسهل الفهم للمبتدئين يسمح بأتمتة إدخال بيانات البطاقات الائتمانية على المواقع المختلفة.

## ✨ المميزات

- 🎨 **واجهة بسيطة جداً** - مصممة للمبتدئين
- 🌐 **إضافة مواقع مخصصة** - احفظ مواقعك المفضلة
- 📱 **سهلة الاستخدام** - 3 خطوات فقط!
- 💾 **حفظ تلقائي** - البيانات تُحفظ تلقائياً
- ⚡ **سريعة وآمنة** - معالجة أخطاء متقدمة

## 🚀 التثبيت

### المتطلبات
- Python 3.7 أو أحدث
- Chrome مثبت على الجهاز

### خطوات التثبيت

```bash
# 1. استنساخ المشروع
git clone https://github.com/bear2156/credit-card-bot.git
cd credit-card-bot

# 2. تثبيت المكتبات
pip install -r requirements.txt

# 3. تشغيل التطبيق
python main.py
```

## 📖 طريقة الاستخدام

### الخطوة 1️⃣: أدخل بيانات البطاقة

```
💳 رقم البطاقة: أدخل 16 رقماً
👤 الاسم: أدخل اسمك
📅 الشهر: 1-12
📅 السنة: 2024-2035
🔐 CVV: 3 أرقام من خلف البطاقة
```

### الخطوة 2️⃣: اختر الموقع

```
📦 أمازون
🛒 eBay
💳 PayPal
⭐ أو أضف موقعاً مخصصاً
```

### الخطوة 3️⃣: بدء العملية

- اضغط على **"▶️ بدء الآن"**
- انتظر حتى ينتهي
- لا تغلق المتصفح

## 🌐 إضافة موقع جديد

### الخطوات:

1. اضغط على **"➕ إضافة موقع"**
2. أدخل:
   - **اسم الموقع** (مثال: ألي بابا)
   - **رابط الموقع** (مثال: https://www.alibaba.com)
   - **Selectors** (اختياري - للمستخدمين المتقدمين)
3. اضغط **OK**
4. اختره من القائمة

## 🔍 ما هي CSS Selectors؟

هي طريقة للعثور على حقول البطاقة في الموقع:

```
أمثلة:
- #card-input      → العنصر بـ id="card-input"
- .card-class      → العنصر بـ class="card-class"
- input[name="card"] → input بـ name="card"
```

### كيفية الحصول عليها:

1. افتح الموقع في المتصفح
2. انقر بزر الماوس الأيمن على حقل البطاقة
3. اختر **"Inspect"** أو **"فحص العنصر"**
4. ابحث عن `id=` أو `class=`
5. انسخه إلى حقل الـ Selector

## ⚠️ تحذيرات مهمة

1. **استخدم ببحذر** - استخدم فقط مع المواقع الموثوقة
2. **بيانات حقيقية فقط** - لا تستخدم بيانات وهمية
3. **شروط الخدمة** - تأكد من توافق الاستخدام مع سياسات الموقع
4. **ملف حفظ آمن** - احم ملف `custom_sites.json`

## 🛠️ استكشاف الأخطاء

### المشكلة: لا يفتح المتصفح

**الحل:**
```bash
pip install webdriver-manager
```

### المشكلة: الحقول لا تمتلأ

**الحل:**
1. افتح الموقع في المتصفح
2. انقر بزر الماوس الأيمن على الحقل
3. اختر "Inspect"
4. ابحث عن `id=` أو `class=`
5. استخدمه في إضافة الموقع

### المشكلة: رسالة خطأ عند التشغيل

**الحل:**
```bash
# أعد تثبيت المكتبات
pip install --upgrade -r requirements.txt
```
